Installed

ZigSolver is in your Applications folder. Open it and type the address of your bot host — there is no second field, because the solver is this app's own and it starts with the window.

The first launch takes longer than the rest: the solver loads its models before it answers anything, and the app shows you how long it has been at it. Show log is the solver's own output if it does not come up.

If the setup step failed — no network, an interrupted download — the whole transcript is in /Library/Application Support/ZigSolver/install.log, and you can run it again without reinstalling:

sudo '/Library/Application Support/ZigSolver/runtime/provision.sh'
